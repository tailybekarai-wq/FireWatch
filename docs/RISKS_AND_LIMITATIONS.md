## 4. Принципиальные ограничения системы (говорятся прямо)

1. **Система не обнаруживает пожары сама.** Она агрегирует, обогащает и ранжирует обнаружения NASA FIRMS.
2. **«Раннее» обнаружение ограничено физикой:** полярные спутники пролетают над точкой несколько раз в сутки, NRT публикуется до 3 часов после пролёта. Пожар, начавшийся между пролётами, система увидит только при следующем пролёте.
3. **Координата — это центр пикселя** 375 м (VIIRS) или ~1 км (MODIS). Точность локализации не выше размера пикселя.
4. **ML-оценка не является подтверждением.** Это вероятность связи с картируемой гарью по версии конкретной модели.
5. **Статус «подтверждённый пожар» в MVP не используется:** нет доступного достоверного оперативного источника для произвольной территории.
6. **Погода является фактором опасности, а не доказательством пожара.** ERA5 доступна с задержкой около 5 дней, для свежих событий используется прогнозная модель.
7. **Sentinel-2 не является оперативным источником:** пролёт раз в 2–5 дней, облачность. Используется только для оценки гари постфактум (опционально).
8. **Покрытие ограничено выбранной территорией** из-за лимита бесплатной БД.
