# Критерии приёмки

Проект считается готовым, когда **все** пункты категории M выполнены и **проверены** (указан способ проверки). Пункты S желательны.

## 1. Достоверность данных (все M)

| # | Критерий | Как проверяется |
|---|---|---|
| A-1 | В рабочей БД нет ни одной записи, не полученной из внешнего источника | SQL: у каждой `detections` есть `first_fetch_id` → `source_fetches.http_status = 200` и реальный `source_id`. Тест-«сторож» в CI против продакшен-реплики (read-only) |
| A-2 | В коде frontend нет захардкоженных данных наблюдений | Code review и поиск по `web/` (нет JSON с координатами или счётчиками, кроме конфигурации) |
| A-3 | 10 случайных обнаружений совпадают с выгрузкой FIRMS (координаты, время, FRP, confidence) | Ручная сверка, протокол в `docs/findings/` |
| A-4 | Каждое число на дашборде совпадает с SQL-запросом за тот же период | Сверка 4 KPI и 1 графика |
| A-5 | При недоступности источника UI показывает ошибку и время последнего успешного обновления, нули не подставляются | Тест с неверным ключом (DEPLOYMENT_PLAN, шаг 7.6) и e2e с остановленным API |
| A-6 | Пробелы в данных на графиках отличаются от нулевых значений | e2e или визуальная проверка на искусственно пропущенном запуске в тестовой среде |
| A-7 | Нигде в UI обнаружение не названо «пожаром» или «подтверждённым пожаром» | Поиск по строкам локализации и ревью экранов |
| A-8 | У каждого обнаружения видны источник, ссылка, время наблюдения, время получения и статус | Детальная страница |

## 3. ML

| # | Критерий | Приор. |
|---|---|---|
| M-1 | Обучающая выборка построена из реальных архивов (FIRMS, MCD64A1, Open-Meteo), хэш датасета зафиксирован | M |
| M-2 | Валидация временная и пространственная, с группировкой по кластеру. Есть тест на отсутствие утечки | M |
| M-3 | Отчёт содержит PR-AUC, ROC-AUC, Precision, Recall, F1, Brier с 95 % ДИ и сравнение с двумя baseline | M |
| M-4 | Решение `active` или `rejected` принято строго по ML_STRATEGY §8 и задокументировано | M |
| M-5 | Модель воспроизводима (seed, версии, артефакт с SHA-256 в GitHub Release) | M |
| M-6 | SHAP-объяснения в карточке обнаружения | S |

*Примечание:* успешным результатом этапа ML считается **корректно проведённый и задокументированный эксперимент**, даже если модель отклонена. Заранее заданного порога точности нет.
