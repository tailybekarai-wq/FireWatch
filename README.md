# FireWatch

Спутниктік деректер мен машиналық оқыту әдістері негізінде орман өрттерін ерте анықтауға арналған ақпараттық жүйе. Аумақ: **Қазақстан Республикасы**.

> **Мәртебесі:** 10 кезеңнің 1-кезеңі, репозиторийдің қаңқасы дайын. Жүйенің функциялары әлі іске асырылмаған. Жоспар: [docs/DEVELOPMENT_ROADMAP.md](docs/DEVELOPMENT_ROADMAP.md).
>
> Толық жобалық құжаттама `docs/` каталогында орыс тілінде берілген.

## Негізгі қағида

Жүйе **тек нақты спутниктік бақылауларды** көрсетеді (NASA FIRMS: VIIRS NOAA-20, NOAA-21, MODIS). Жұмыс дерекқоры мен интерфейсте ойдан шығарылған деректерді пайдалануға тыйым салынады. Әрбір спутниктік анықтау расталған өрт емес, жылулық аномалия болып саналады.

## Құрылымы

| Каталог | Мақсаты | Орналастыру |
|---|---|---|
| `web/` | Пайдаланушы интерфейсі (Next.js, TypeScript, Tailwind) | Vercel |
| `api/` | Тек оқуға арналған REST API (FastAPI) | Render |
| `pipeline/` | Деректерді жинау, тексеру, сақтау және ML-бағалау | GitHub Actions (кесте бойынша) |
| `ml/` | Модельді оқыту және бағалау | GitHub Actions (қолмен іске қосу) |
| `shared/` | Python компоненттеріне ортақ схемалар мен тұрақтылар | — |
| `docs/` | Жобалық құжаттама | — |

Архитектура: [docs/SYSTEM_ARCHITECTURE.md](docs/SYSTEM_ARCHITECTURE.md).

## Жергілікті әзірлеу

Қажетті құралдар: Python ≥ 3.12, Node.js 24 LTS, Git.

```bash
python -m venv .venv
```

Виртуалды ортаны белсендіру: Windows жүйесінде `.venv\Scripts\activate`, Linux/macOS жүйесінде `source .venv/bin/activate`.

```bash
pip install -r requirements-dev.txt
```

```bash
pre-commit install
```

```bash
pytest
```

Веб-интерфейс:

```bash
cd web && npm install && npm run dev
```

Орта айнымалылары [.env.example](.env.example) файлында сипатталған. Нақты мәндер тек `.env` файлында (ол `.gitignore` тізімінде) және GitHub, Render, Vercel құпияларында сақталады.
